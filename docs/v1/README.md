# NEXUS v1 (retired)

These documents describe the first version of NEXUS: a standalone 47k-line Python
system (own LLM router, wake word, Qt HUD, gaming mode). It was retired in
September 2026 and replaced in October 2026 by v2, a small personal layer on top of
[Phantom](https://github.com/Julian-Rincon/phantom). See the main [README](../../README.md)
for why.

They are kept as a record of the design, not as a description of what runs today.
